# 0022. Старое видео при замене в корзину не идёт

## Контекст

Любая замена в песне до сих пор отправляла старую версию в корзину (ADR 0006), но видеофайл весит сотни МБ, а корзина живёт в томе data.

## Решение

При замене или удалении видео старый файл удаляется после записи нового; в корзину уходит только прежняя версия `.txt`. Удаление песни целиком по-прежнему переносит в корзину всю папку вместе с видео.

## Почему

- **Класть старое видео в корзину, как всё остальное** отвергнуто: несколько замен быстро съедают диск ПК, а файл почти всегда можно скачать по ссылке заново.
- **Не удалять старый файл вовсе** отвергнуто: на шаре копились бы ролики, на которые не ссылается ни один `.txt`.

## Последствия

- Восстановление `.txt` из корзины после замены видео вернёт `#VIDEO` на уже удалённый файл — песня останется без видео до повторного прикрепления.
- Нарушена общая гарантия «любую правку можно откатить из корзины»; диалог обязан предупреждать «старое видео удалится».
- Своего файла пользователя, загруженного с ПК, больше нигде нет — вернуть его можно только повторной загрузкой.
