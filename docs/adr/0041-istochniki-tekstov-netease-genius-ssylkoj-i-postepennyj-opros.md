# 0041. Источники текстов: NetEase с синхронизацией, Genius только ссылкой, показ по мере ответа

## Контекст

LRCLIB часто недоступен. Пользователь попросил ещё сервис и привёл Genius. Проверено 2026-10-28: lyrics.ovh не находит русские песни, Musixmatch и LyricFind не отвечают, AZLyrics режет ботов. NetEase (music.163.com) работает без ключа и отдаёт синхронный LRC, в том числе для русских песен. Страницы Genius с сервера закрыты проверкой Cloudflare. Источники отвечают с разной скоростью.

## Решение

Источники — LRCLIB, NetEase, Genius под одним интерфейсом провайдера. NetEase даёт до 5 вариантов с признаком синхронизации. Genius даёт только ссылку на страницу (текста нет): пользователь открывает её в браузере и вставляет текст в диалог сам. Проверку Cloudflare не обходим. Диалог поиска шлёт по запросу на источник (`source=`) параллельно и дорисовывает варианты по мере ответа; без `source` сервер опрашивает все параллельно и сам собирает ответ (для авто-поиска папки). Синхронные варианты идут первыми; недоступный источник — строка статуса, общая ошибка — только когда не ответил никто.

## Почему

- **Получать текст Genius на сервере (обход Cloudflare, headless-браузер, прокси)** отвергнуто: хрупко, это обход защиты сервиса, тянет тяжёлую зависимость в домашний сервис ради одного источника и ломается без предупреждения.
- **Не добавлять Genius, ограничиться NetEase** отвергнуто: пользователь назвал Genius; ссылка плюс ручная вставка закрывают случай «знаю, что текст там» ценой двух действий.
- **Ждать всех источников и показать общим списком** отвергнуто: самый медленный (таймаут до 10–15 с) задерживал бы варианты быстрых, а при недоступном LRCLIB диалог казался бы зависшим.
- **Постепенный опрос с клиента и в авто-поиске папки** отвергнут: там идёт много песен подряд, выгоднее один запрос на песню с серверным слиянием.
- **Другие сервисы (Яндекс Музыка, Musixmatch, lyrics.ovh)** не взяты по причинам выше; Яндексу нужны запросы, подписанные ключом приложения, — отложено.

## Последствия

- NetEase — неофициальный интерфейс без обязательств: он может измениться или закрыться, поэтому сбой источника — штатный случай и остальных не ломает. Служебные строки авторов в его текстах отсекает фильтр, который придётся поддерживать.
- Совпадения NetEase ищутся по исполнителю и названию, ложные попадания возможны; поэтому у каждого варианта есть «Просмотр» целиком до вставки.
- Genius остаётся ручным шагом: его текст всегда без синхронизации и вставляется как обычный вариант; авто-поиск папки его не использует.
- Идентификатор варианта теперь `"<источник>:<id>"`, клиенты и тесты обязаны знать про источники.
- Один поиск превращается в несколько внешних запросов, нагрузка на сторонние сервисы растёт.
