# 0017. Строка дуэта «оба» пишется копией в P1 и P2

## Контекст

Дуэт должен позволять отдать строку обоим певцам. В формате UltraStar для этого есть два пути: метка `P3` или повтор строки в обоих блоках.

## Решение

Файл дуэта содержит только блоки `P1` и `P2`. Строка «оба» записывается двумя одинаковыми копиями — по одной в каждый блок. При открытии строки P1 и P2 с полностью одинаковыми нотами показываются одной строкой «оба».

## Почему

- **Метка `P3`** отвергнута: её читают не все плееры, а песня должна петься на Pi и в любой программе, куда её потом унесут; usdb тоже пишет только `P1`/`P2`.
- **Хранить «оба» отдельно (в БД или своём заголовке)** отвергнуто: файл перестал бы быть единственным источником правды, а чужие песни с шары такой разметки не имеют.

## Последствия

- «Оба» — не сохранённый факт, а вывод из совпадения нот: если певцы случайно спели одинаковую строку раздельно, редактор покажет её как «оба»; правка одной копии вне редактора молча разделит строку.
- Каждая строка «оба» удваивает свой размер в файле и требует двух источников при сопоставлении правок.
- Отказаться потом от дублирования означает переписать уже выложенные дуэты.
