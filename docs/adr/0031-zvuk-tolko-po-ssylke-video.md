# 0031. Недостающий звук берётся только из копии или по ссылке `#VIDEO`

## Контекст

«Проверка библиотеки» находит песни без звука, и для каждой находки нужна кнопка исправления. Самое удобное — найти звук автоматически по названию.

## Решение

Исправление `no_audio` предлагает три действия: взять звук из копии в другом хранилище (copy с заменой), скачать по ссылке из `#VIDEO` отдельным заданием `audio` без GPU или отправить песню в корзину. Ссылка берётся только из `#VIDEO` (YouTube, usdb `v=`); без неё задание `audio` отвечает 409.

## Почему

- **Поиск звука по названию** отвергнут: ноты размечены под конкретную запись, а другая версия, живая запись или ремастер даст рассинхрон, который молча портит песню и виден только при пении.
- **Скачивать звук из любой ссылки в `#VIDEO`** отвергнуто: ссылка `a=` ведёт на звук без видео, а ссылки на сторонние сайты yt-dlp не разберёт — ошибка была бы непонятна пользователю.

## Последствия

- Песни без `#VIDEO` и без копии исправляются только вручную; кнопка серая с причиной.
- Если видео по ссылке удалено, остаётся только корзина.
- Звук по ссылке может оказаться другой длительности, чем тот, под который размечены ноты; автоматически это не проверяется.
