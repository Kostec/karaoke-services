# 0021. Свой файл видео кладётся как есть

## Контекст

Пользователь может прикрепить видео файлом любого распространённого контейнера, а Pi проигрывает не всё одинаково хорошо.

## Решение

Загруженный файл копируется в папку песни без перекодирования, с исходным расширением; проверяются только расширение и размер (`MAX_VIDEO_MB`).

## Почему

- **Перекодирование в H.264/mp4** отвергнуто: без NVENC в образе ролик в несколько сотен МБ кодировался бы на CPU десятки минут и забирал бы воркер у генерации.
- **Перекодирование на GPU через CUDA-сборку ffmpeg** отвергнуто: усложняет образ worker, а GTX 1080 нужна UltraSinger.
- **Принимать только mp4** отвергнуто: пользователь выбрал файл сам и сам отвечает за его формат; mkv/webm у него встречаются.

## Последствия

- Файл, который Pi не тянет, выкладывается без предупреждения; это видно только при пении.
- Лимит в 2000 МБ при медленной шаре делает задание долгим.
- Добавить перекодирование позже — отдельная опция, а не смена поведения по умолчанию, иначе уже привычный путь замедлится.
