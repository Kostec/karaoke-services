# 0019. Видео прикрепляется отдельным заданием `video` без GPU

## Контекст

Видео нужно добавлять, заменять и убирать у любой песни на шаре, а запись в папку результата до сих пор шла только из воркера.

## Решение

Прикрепление видео — отдельное задание `video` с `needs_gpu=False`, устроенное как минусовка: воркер читает песню из папки результата, кладёт файл рядом и меняет только заголовки `#VIDEO`/`#VIDEOGAP`. Веб ставит задание и на шару сам не пишет.

## Почему

- **Запись прямо из веба** отвергнута: появился бы второй писатель в папку результата со своими повторами для Samba на Pi, а скачивание по ссылке длится минутами и не вписывается в HTTP-запрос.
- **Перегенерация песни с видео** отвергнута: видео не связано с нотами, а гнать UltraSinger ради заголовка — долго и требует GPU.
- **Правка через «Редактор нот»** отвергнута: тот меняет только `.txt`, а видео — большой отдельный файл.

## Последствия

- Видео встаёт в общую очередь: пока идёт генерация, прикрепление ждёт, хотя GPU ему не нужен.
- Появляется ещё один тип задания, который надо учитывать в отмене, перезапуске, повторной выкладке и проверке дублей (второе видео той же песни — 409).
- Большой файл пользователя сначала грузится в том data, потом копируется на шару — двойной трафик и место на время задания.
