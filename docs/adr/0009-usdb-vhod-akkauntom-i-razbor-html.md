# 0009. usdb — вход под аккаунтом пользователя и разбор HTML; ultrastar-es — только файлом

## Контекст

У usdb.animux.de нет публичного API: песни отдаются только после входа и только через HTML-страницы. У пользователя есть свой аккаунт. У ultrastar-es.org API тоже нет, и сайт отвечает 403 на запросы не из браузера (проверено 2026-10-20).

## Решение

`UsdbClient` в web входит в usdb POST-запросом с логином и паролем пользователя из «Настроек» (`settings['usdb']`) и держит cookie сессии в памяти процесса. Если ответ показывает, что входа нет, клиент один раз входит заново. Поиск, ноты и детали он получает разбором HTML. Строки, по которым распознаются ошибки, взяты из usdb_syncer. Встроенного поиска по ultrastar-es.org нет: песни оттуда импортируются файлом или ссылкой.

## Почему

- **Подключить usdb_syncer как библиотеку** отвергнуто. Это настольное приложение с GUI и своей БД, а не пакет с API. Тянуть его в образ web ради четырёх запросов дороже, чем повторить их и взять из него только проверенные строки-признаки.
- **Общий служебный аккаунт или учётка в переменных окружения** отвергнуты. Доступ в usdb привязан к личному аккаунту. Учётку из `.env` нельзя поменять из браузера и проверить кнопкой, а пароль шары уже хранится в БД, и usdb следует тому же образцу.
- **Скрейпинг ultrastar-es.org с подменой User-Agent или через headless-браузер** отвергнут. 403 — явный отказ сайта ботам: обход хрупок и идёт против воли сайта, а headless-браузер — тяжёлая зависимость в образе ради одного источника. Импорт zip покрывает этот сборник без всякого обхода.

## Последствия

- Вёрстка usdb становится нашим контрактом, хотя никто его не гарантирует: смена HTML-таблицы или текста ошибок тихо ломает поиск. Тесты работают на сохранённых образцах страниц и такую поломку не поймают.
- Пароль usdb лежит в SQLite открытым текстом, как и пароль шары, и попадает в бэкап тома.
- Сессия живёт в памяти web, поэтому после перезапуска контейнера первый запрос тратит время на лишний вход. Если запустить несколько воркеров uvicorn, каждый будет входить сам.
- Все запросы идут от имени пользователя. Если usdb ограничит или заблокирует аккаунт за частые запросы, пострадает его личная учётка.
- Песни с ultrastar-es.org пользователю приходится скачивать архивом в браузере и загружать в приложение вручную.
