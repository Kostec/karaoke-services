## Что должно заработать

В карточке песни вместо «Править слова» — «Редактор нот». Окно почти на весь экран по согласованному макету `design.html`: шапка (↶ ↷, состояние правок, «Сохранить», ✕), панель инструментов (▶/пауза, «▶ строка», время, скорость, «Следовать», масштаб, «Выделить всё», действия с выбранным), таймлайн (линейка, волна, ноты по высоте с подписями октав, дорожка слогов, границы строк, курсор), подсказка снизу. Звук — настоящий из `/audio`. Правка мышью и клавишами через модель из таска 02, сохранение через PUT из таска 01. Правую панель текста, отстукивание, сдвиг текста/разрезать/слить/новая строка и справку `?` делает таск 04 — здесь для них оставить место в разметке (панель справа может быть пустой заготовкой).

Прежние `lines-editor.js`, `lines.js` и `tests/frontend/lines.test.mjs` удалить (полезные проверки — уже в модели таска 02).

## Критерии приёмки

- [ ] В карточке песни одна кнопка «Редактор нот» (id `notes`), «Править слова» нет; дуэт/`#RELATIVE`/без `#BPM` — просмотр с баннером; ошибка загрузки — баннер
- [ ] ▶/пауза (`Пробел`), «▶ строка» (`L`), клик по линейке/волне, скорость 0.5/0.75/1× без смены тона, «Следовать»; курсор, звучащая нота и слог подсвечены; нет аудио — ▶ неактивны с причиной
- [ ] Волна строится из аудио (индикатор «Строю волну…», ошибка или файл > 60 МБ — «Волна недоступна»), рисуется только видимая часть
- [ ] Ноты по высоте, слоги под нотами, золотые/freestyle/rap различимы, пустой слог `∅` красным, перекрытия красным
- [ ] Перетаскивание ноты (время + высота), ручки краёв (длительность), рамка и `Shift`+клик, стрелки/`Shift`/`Ctrl`; двойной клик по пустому — новая нота с вводом слога, `N`; `Delete`; двойной клик по слогу / `F2` / `Enter` — правка, `Tab`/`Shift+Tab`, `Esc`; `G` — золотые; «Выделить всё»/`Ctrl+A` + сдвиг/тональность
- [ ] ↶ ↷ / `Ctrl+Z`, `Ctrl+Shift+Z`; `Ctrl+S`; сохранение с проверкой перекрытий (переход к первой), «Сохранено. Прежняя версия .txt — в корзине.», ошибка — правки остаются; переспрос при закрытии с правками
- [ ] Клавиши по `code` (работают в русской раскладке), не срабатывают в полях ввода; масштаб `Ctrl`+колесо и `+`/`−` с сохранением центра и запоминанием; светлая и тёмная тема; видимый фокус, `title`/`aria-label` у кнопок
- [ ] Плавно на песне в 1500 нот (при перетаскивании не перерисовывается весь таймлайн); на ширине телефона окно во весь экран, выбор касанием и кнопки работают
- [ ] `node --test tests/frontend/` зелёный; проверено вручную в браузере на реальной песне (запуск `./scripts/compose.ps1 up -d --build`, http://localhost:8090)
