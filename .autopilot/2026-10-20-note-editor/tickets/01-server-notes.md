## Что должно заработать

`GET /api/songs/{id}/notes` отдаёт у каждой ноты `id` — её порядковый номер в исходном файле. `PUT` того же адреса принимает любую правку нот: новые время/длину/высоту/тип/текст, удалённые ноты, новые ноты (`id: null`), новые границы строк и новый `gap`. Неизменённое пишется байт в байт, неизменённый файл не трогается вовсе, прежняя версия уходит в корзину (как сейчас). Прежний запрет «Тайминги и высоты нот менять нельзя» снимается. Песня без `#BPM` теперь только для просмотра (`editable: false`, `reason`), PUT → 409.

## Критерии приёмки

- [ ] GET: у нот `id` 0…N-1 по порядку в файле; песня без `#BPM` — `editable: false` и `reason` «В песне нет #BPM — редактор только для просмотра»
- [ ] PUT без правок — файл не меняется, корзина не трогается; правка одной ноты меняет только её строку файла (остальное байт в байт, кодировка/BOM/переводы строк сохранены)
- [ ] PUT с изменённым временем, длиной, высотой, типом, удалённой и добавленной нотой, новой границей строки — результат в файле верный и читается обратно GET

- [ ] Неразобранные строки тела остаются перед своей нотой (удалена — перед следующей уцелевшей); всё после `E` как было
