# 05 — Сдвиг текста по нотам: слово / строка / вся песня, кнопки, клавиши, перетаскивание слога

**Волна:** 4

## Что должно заработать

Ноты стоят правильно, а текст местами съехал на одну-две ноты — по всей песне, внутри строки или внутри слова. Пользователь выбирает область (слово · строка · до конца песни) и сдвигает текст кнопками «⇠ текст / текст ⇢», `Alt+←/→` или перетаскиванием слога мышью по дорожке слогов. Текст не теряется, ноты и границы строк не двигаются.

## Из брифа, дословно

> «Не хватает функции сдвига текста по нотам. Например, ноты правильные, но текст местами требует смещения. Я вынужден переписывать весь текст по нотам»
> «Можно ли предусмотреть все варианты, я не текст может быть как смещён по всей песне, так и смещён в рамках одной строки или слова»

## Критерии приёмки

- [ ] `shiftTextBy(state, id, k, scope)` в модели: вправо/влево, k > 1, три области, перелив последнего слога, «~» с пробелами, неизвестный id, отказ влево у первой ноты области — тестами; `shiftText` — через неё, без прежнего отказа
- [ ] Переключатель области в панели инструментов, запоминается (localStorage с try/catch), по умолчанию «строка»; кнопки и `Alt+←/→` используют его; подсказки кнопок называют область
- [ ] Перетаскивание слога по дорожке на другую ноту сдвигает текст на K нот в выбранной области, с подсказкой во время перетаскивания; клик/двойной клик по слогу работают как раньше
- [ ] Каждый сдвиг — один шаг отмены; справка `?` описывает сдвиг и переключатель
- [ ] `node --test tests/frontend/` зелёный; проверено в браузере на реальной песне без сохранения
