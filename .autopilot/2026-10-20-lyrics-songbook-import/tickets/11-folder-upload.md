## Что должно заработать

В «Импорте» новая вкладка «Папка». Пользователь выбирает папку целиком. Сервис раскладывает файлы на две группы и показывает обе на одном экране:

1. **Готовые песни UltraStar** — всё, что относится к .txt-песням (сами .txt, их аудио, обложки, минусовки), уходит одним inspect `source=files` с относительными путями и показывается теми же карточками, что для zip (галочки, звук, минусовка, «Заменить»).
2. **Музыка для генерации** — mp3, на которые не ссылается ни один .txt. По строке на трек: исполнитель/название из ID3 (`id3.js`), иначе из имени файла «Исполнитель - Название.mp3» (иначе имя файла как название, исполнитель пустой и подсвечен); «уже есть» через `/api/songs/exists`; для каждого трека автоматически ищется текст в LRCLIB (первый вариант из `usableHits`), в строке видно «текст найден» / «есть синхронизация» / «текст не найден — слова распознаются автоматически», вариант можно сменить тем же диалогом, что в форме новой песни. Параметры генерации (модель, язык и т.д.) — одни на всю группу, из `/api/defaults`.

Кнопки «Импортировать выбранные» и «Сгенерировать выбранные» ставят задания по одному (`api.importJob` и существующий `generateForm` → `api.generate`), с ходом «Поставлено N из M»; ошибка одного трека — в его строке, остальные продолжаются; в конце — ссылка в очередь.
