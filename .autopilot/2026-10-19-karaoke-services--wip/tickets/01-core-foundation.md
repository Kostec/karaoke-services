## Что должно заработать

Репозиторий по структуре §12. Пакет `karaoke_core` с модулями `db`, `naming`, `ultrastar`, `postprocess` и полным набором тестов, которые гоняются в Linux-контейнере `tests`.
- Из фикстуры «выход UltraSinger» функция `finalize()` делает готовую песню: ARTIST и TITLE из формы, фильтр MusicBrainz, без нулевых нот, файлы переименованы в «Исполнитель - Название…».
- Очередь в SQLite атомарно отдаёт задания по одному.

Каркас `docker-compose.yml`:
- сервисы `web`, `worker`, `tests` (профиль `test`), именованные тома `data` и `models`;
- Dockerfile'ы web и worker пока минимальные заглушки: worker наполнит таск 03, web — таск 05;
- `tests` собирается из `python:3.12-slim` и ставит `core` и dev-зависимости (pytest).

`.env.example` содержит все переменные из спецификации с комментариями по-русски. `.gitignore` уже есть: дополнить, не перезаписывать. `scripts/compose.ps1` — обёртка `docker --context desktop-linux compose @args`.

## Критерии приёмки

- [ ] `docker --context desktop-linux compose --profile test run --rm tests` проходит зелёным
- [ ] `ultrastar.parse→render` воспроизводит байт в байт фикстуры: UTF-8 от UltraSinger, UTF-8 с BOM и CRLF, cp1251 с USDB, дуэт P1/P2
- [ ] `set_header_line` вставляет или заменяет `#INSTRUMENTAL` и не меняет ни одного другого байта (тест на cp1251 + CRLF)
- [ ] `fix_zero_length`: после исправления нет нот длины 0 и перекрытий; тексты и порядок слогов прежние; разрывы строк не раньше конца предыдущей ноты
- [ ] `finalize`:
  - ARTIST/TITLE взяты из аргументов;
  - при несовпадении исполнителя MusicBrainz удалены обложка, `#COVER`, `#YEAR`, `#GENRE`;
  - обложка из формы ставится как `[CO]`;
  - все файлы и ссылки переименованы: `#MP3`/`#AUDIO` → оригинал, `#INSTRUMENTAL` → `[Instrumental].mp3`, `#VOCALS` → `[Vocals].mp3`;
  - `cache/` не попадает в результат
- [ ] `naming.safe_name` заменяет `/ \ : * ? " < > |` и управляющие символы, убирает точки и пробелы в конце; `song_dir` → `<A>/<A - T>`
- [ ] `Jobs.claim_next` из двух конкурирующих соединений никогда не отдаёт одно задание дважды; `fail_interrupted` переводит running и publishing в failed с текстом «прервано перезапуском»
- [ ] `.env.example` перечисляет все переменные; в репозитории нет ни одного пароля
