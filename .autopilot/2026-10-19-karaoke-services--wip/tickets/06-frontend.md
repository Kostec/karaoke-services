## Что должно заработать

Одна страница без сборки (HTML, CSS, ES-модули), на русском, удобная на телефоне. Разделы:
- **шапка**: статус GPU и папки результата;
- **«Очередь»**: карточки заданий с этапом, процентом и временем, раскрываемый живой лог (SSE), кнопки «Отменить», «Перезапустить», «Выложить повторно», пустое состояние;
- **«Новая песня»**:
  - поля: исполнитель, название, mp3, текст (вставка или файл .txt/.lrc), обложка;
  - модель и язык; «Дополнительно» с тонкими параметрами;
  - предупреждение без текста;
  - проверка «Такая песня уже есть» с выбором «Заменить» / «Отмена»;
  - блокировка повторной отправки;
- **«Песни»**: поиск, обложки, признаки; действия «Удалить» (подтверждение), «Перегенерировать», «Минусовка» / «Пересоздать минусовку»; кнопка пересканирования и время индекса; баннер недоступности. Места для кнопок «Редактировать текст» и «Редактировать слова» оставлены для таска 07;
- **«Корзина»**: восстановление и дни до удаления;
- **«Настройки»**: папка результата с проверкой; для локальной цели показывается Windows-путь.

## Из брифа, дословно

> «простой адаптивный фронтенд, интерфейс на русском»
> «чтобы добавлять песни из браузера (в т.ч. с телефона в домашней сети)»
> «список готовых песен с возможностью удалить/перегенерировать»
> «Предупреждать в форме; при замене старая в корзину.»

## Разделы спецификации

Истории 3, 6–21, 34–47 (интерфейсная часть); Решения §11.

## Критерии приёмки

- [ ] Проверено во встроенном браузере при ширине 360 и 1280 px: нет горизонтальной прокрутки, кнопки ≥ 44 px, светлая и тёмная темы
- [ ] Полный путь «Новая песня → в очереди → лог → готово → песня в списке» работает с запущенным стеком
- [ ] Ошибки API показываются текстом `detail`, введённые поля не теряются
- [ ] Пустые состояния очереди, списка и корзины соответствуют истории 6
- [ ] Удаление с подтверждением, затем восстановление из корзины
- [ ] В интерфейсе нет английских строк
