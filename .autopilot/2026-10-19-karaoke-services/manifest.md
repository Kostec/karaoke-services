## Факты, выясненные до брифинга (2026-10-19)

- Docker Desktop 29.8.2: активен контекст `desktop-windows`, но Linux-движок (`desktop-linux`) работает параллельно и имеет runtime `nvidia`. Compose надо направлять в `desktop-linux`.
- Имя `pi` внутри контейнеров **не резолвится** (на хосте — через mDNS `pi.local` → 192.168.0.129). Для CIFS нужен IP/адрес в `.env`.
- Шара `\pi\karaoke` подключена в Windows без буквы диска (K: в этой сессии нет).
- Правки UltraSinger **не закоммичены**: 4 изменённых файла + новый `lyrics_alignment.py` (intent-to-add). `local_changes.diff` старее рабочего дерева (нет дампа lyrics_debug.json), `apply_patch.py` не создаёт `lyrics_alignment.py` и не чинит `midi_creator.py`.
- Dockerfile UltraSinger ставит torch 2.8.0 с индекса cu128; Linux-колёса cu128, по всей видимости, без sm_61 (Windows-колесо — с sm_61). Проверить `get_arch_list()` в образе, при необходимости — индекс cu126.
- UltraSinger всегда ходит в MusicBrainz (флага выключения нет), имя папки непредсказуемо (+` (1)` при совпадении), имена не санитизируются. Прогресса в процентах нет — только маркеры этапов.
- Ноты нулевой длины возникают в .txt (`duration` округляется до 0); фикс в midi_creator касается только MIDI.
- `.lyrics.txt` в папке песни UltraStar может принять за песню (сканирует *.txt) — исходники для перегенерации хранить вне шары.

## Состязательный проход (находки)

1. Провал: сервис есть, но песни «не видны» — UltraStar не пересканировал папку / CIFS-монтирование отвалилось после перезагрузки Pi, задания молча падают. → видимый статус шары в UI, результат сначала локально, выкладка с повтором.
2. Столкновение: R12 «перегенерировать» и R11 «список готовых» — для песен с USDB нет исходного текста/mp3-источника в нашем хранилище. → вопрос.
3. Непроверенное: «правки сохранятся» — сейчас они живут только в незакоммиченном рабочем дереве. → вопрос.
4. Цена: живой лог + прогресс — без процентов от UltraSinger прогресс только по этапам.
5. Условие: удаление песни с шары необратимо. → вопрос.
6. Вторая неделя: дубли «Исполнитель - Название», повторная генерация той же песни. → решаю: перегенерация заменяет папку целиком, новая с тем же именем — предупреждение в форме.
7. Второй актор: гости с телефонов в домашней сети — могут удалять песни. → вопрос про защиту.
