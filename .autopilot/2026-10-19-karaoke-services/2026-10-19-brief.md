# Проект karaoke-services

## Контекст
Делаю домашнюю караоке-систему с оценкой пения:
- **Плеер:** Raspberry Pi 5 (Raspberry Pi OS 64-bit, hostname `pi`, пользователь `pi`), UltraStar Deluxe 2026.10.0 из Flathub.
  Папка песен: `/home/pi/.var/app/eu.usdx.UltraStarDeluxe/.ultrastardx/songs/`, расшарена по Samba как `\\pi\karaoke`
  (на Windows подключена как диск `K:`). Подпапки допускаются, одна песня = одна папка.
- **Генерация песен:** Windows-ПК с NVIDIA GTX 1080 (8 ГБ, Pascal), UltraSinger в `D:\Projects\UltraSinger`
  (Python 3.12, окружение через uv, запуск `src\UltraSinger.py`).
- Репертуар в основном русский рок/метал (Stigmata, Король и Шут, Мельница) — в базах USDB его почти нет, поэтому песни генерируются UltraSinger'ом.

## Локальные правки UltraSinger (уже сделаны, должны сохраниться)
Лежат в `D:\Projects\UltraSinger\local_patch\` (`local_changes.diff`, `apply_patch.py`):
- `src/modules/Speech_Recognition/lyrics_alignment.py` — генерация по готовому тексту: если рядом с mp3 лежит `<имя>.lyrics.txt`
  (или `--lyrics <путь>`), Whisper используется только для таймингов, слова берутся из текста и выравниваются wav2vec2 (whisperx.align).
  Ищет повторы припева, удаляет галлюцинации Whisper («Субтитры сделал DimaTorzok», «Продолжение следует» и т.п.).
  Пишет отладку в `cache/lyrics_debug.json` (нужен `--keep_cache`).
- Новые флаги: `--lyrics`, `--vad_onset`, `--vad_offset`.
- Фикс в `src/modules/Midi/midi_creator.py`: пропуск нот нулевой длины (иначе падение в pretty_midi).

## Проверенная рабочая команда
```
python UltraSinger.py -i "<mp3>" -o "<out>" --whisper large-v2 --whisper_compute_type int8 --whisper_batch_size 4 --language ru --whisper_align_model "jonatasgrosman/wav2vec2-large-xlsr-53-russian"
```
Известные грабли:
- GTX 1080 не умеет эффективный float16 → только `int8`; large-v3 галлюцинирует сильнее, лучше large-v2.
- Без `--language ru` Whisper может принять песню за английскую.
- numba требует `numpy<2.5`.
- Исполнитель/название берутся из имени файла `Исполнитель - Название.mp3` и «уточняются» через MusicBrainz (может подменить название).
- UltraSinger пишет в .txt `#AUDIO`/`#MP3` = оригинал, `#INSTRUMENTAL` = минусовка (Demucs). UltraStar 2026.x в меню играет оригинал,
  при пении микширует по настройке «Громкость вокала» (у нас 0 → только минусовка). Это поведение нужно сохранять.

## Формат текста песни (.lyrics.txt)
UTF-8, одна спетая строка = одна строка файла, все повторы выписаны целиком в порядке звучания.
Метки вида `[Припев]` сейчас просто удаляются (есть идея: метка с текстом определяет блок, пустая метка — повтор блока).

## Задача
Сделать сервис в **docker-compose** на Windows-ПК (Docker Desktop + WSL2 + GPU), чтобы добавлять песни из браузера (в т.ч. с телефона в домашней сети):

### MVP
1. **Web (FastAPI + простой адаптивный фронтенд, интерфейс на русском):**
   - форма «Новая песня»: исполнитель, название, mp3 (загрузка файла), текст (вставка или файл), параметры (модель Whisper, язык);
   - очередь заданий: статус, прогресс, живой лог UltraSinger, кнопки «отменить» / «перезапустить»;
   - список готовых песен с возможностью удалить/перегенерировать;
   - сделать минусовку для существующей песни (например, скачанной с USDB): Demucs → `<имя> [Instrumental].mp3` + строка `#INSTRUMENTAL:` в .txt, не трогая ноты.
2. **Worker:** UltraSinger с нашими правками, GPU, **строго одно задание за раз** (8 ГБ VRAM). Образ собирать из моей копии репозитория
   (сохранить локальные правки; предусмотреть, как переносить их при обновлении upstream).
3. **Постобработка результата:** выставлять `#ARTIST`/`#TITLE` из формы (не из MusicBrainz), чинить ноты нулевой длины,
   складывать в `<Исполнитель>/<Исполнитель - Название>/` в выходной том.
4. **Выходной том** = Samba-шара на Pi (`//pi/karaoke`, CIFS-монтирование в compose или через Windows-диск); учётка через `.env`.
5. Кэш моделей (Whisper, Demucs, wav2vec2, HuggingFace) — в постоянном томе, чтобы не качать заново.

### Позже (не делать в MVP, но заложить в архитектуру)

- Раскрытие меток `[Припев]` в .lyrics.txt.

  потом предложи план и структуру репозитория и **дождись моего подтверждения** перед реализацией.

- Конфигурация через `.env` + `.env.example`, README на русском с инструкцией запуска.
- Не коммить секреты (пароль Samba, учётку USDB).
