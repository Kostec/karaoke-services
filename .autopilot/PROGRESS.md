# karaoke-services — что осталось

Последняя сборка: `.autopilot/2026-10-28-player-remote-lyrics/` — мелодия нот и «Вокал» в редакторе и «Прогоне», кликабельное «пианино», пульт Rii i8 на всех экранах с подсказкой, тексты из LRCLIB + NetEase + Genius (ссылкой) с просмотром, вся очередь видна.

## Договорились — не пересматривать

- Вкладки «Новая песня» в меню и кнопки «+ Новая песня» в «Очереди» нет — только плавающая «+», сразу в форму
- Свои теги — в базе сервиса по «исполнитель — название», файлы песни не меняются; палитра из 8 цветов, по умолчанию синий
- Крупные изменения вида — сначала макет и согласование («Макет ок, собирай» — `.autopilot/2026-10-27-library-tools/mockup.html`)
- Плейлисты (.upl) не делаем: «Пока что не добавляй плейлисты»
- Микрофона нет: «Думаю можно обойтись без микрофона» — вместо него синтезатор нот
- Сервис открывают по `https://karaoke.home` через Caddy с `tls internal`; `http://<IP>:8090` остаётся; основной канал уведомлений — Telegram
- Зеркало само ничего не удаляет: только добавляет и заменяет изменённые
- Звук песни берётся только по ссылке `#VIDEO` или из копии
- «Пульт должен работать на всех вкладках. Он будет подключён к Pi» — браузер с пультом Rii i8 стоит на Pi
- Вокал без минусовки: переключатель неактивен, «Нет минусовки» и «Сделать минусовку» («1. Ок»); выключенный вокал = минусовка с той же секунды
- Тексты Genius сервер не получает (Cloudflare) и обходить это не будем — только ссылка и ручная вставка (решение сборки 2026-10-28, ADR 0041)

## Не доделано

- Экраны этой и прошлой сборки на настоящем Pi с пультом Rii i8 не проверялись (медиаклавиши, звук на слух); «Сделать минусовку» из переключателя «Вокал» не нажималась
- Генерация, минусовка и пакетная генерация по ссылке после сборки 2026-10-27 не запускались (нужен worker с GPU)
- Тексты Яндекс Музыки (по токену аккаунта, с синхронизацией) — вне рамок: нужна подпись запросов ключом приложения
- Громкость вокала ползунком (микс `[Vocals]` + минусовка) — вне рамок, сделан только вкл/выкл

## Известные баги

- Код запасного пути «минусовка не загрузилась» и защиты медиаклавиш повторён в `play.js` и `editors/notes-editor.js`
- На «Песнях» ⏯/`P`/`R` работают только при карточке в фокусе; без фокуса ничего не происходит и подсказки нет
- Смена «Вокала» даёт короткую паузу на загрузку файла (позиция сохраняется)
- Сохранённый токен Telegram-бота нельзя стереть (только заменить) — `api_settings.put_telegram`
- `/api/settings/telegram/test` без `WEB_PASSWORD` шлёт тестовое сообщение в любой chat id
- `telegram._HideBotPath` маскирует только строковые аргументы лога
- Загрузка настроек применяется не одной транзакцией; смена chat id Telegram не видна в предпросмотре; плохой локальный путь отклоняет весь файл общим текстом
- Правила проверки хранилища продублированы в `core/backup.py` и `web/app/api_targets.py`
- Картинка по ссылке может редиректом увести запрос в домашнюю сеть (проверяется только исходный адрес)
- Зеркало: папка, отличная только регистром, на Google Диске даст две папки
- 503 от действия гасит пункты «…» только при следующем опросе (до 15 с)
- «Проверка»: «Найти обложку…» не помечает строку; пометки «Исправлено» живут, пока открыта страница; двойное нажатие «Проверить»/«Синхронизировать» может поставить два задания
- «Зеркала»: подтверждение «Убрать в корзину» не называет песню и хранилище
- Задание `artwork` «убрать» без обложки/фона ставится и ничего не меняет
- Звук по `#VIDEO` для `.txt` вида `song.txt` получит имя `song.mp3`
- `Jobs.schedule` у идущего задания с прошедшим временем отвечает «Время уже прошло» вместо «можно только ожидающее»
- За обратным прокси без `Host`/`X-Forwarded-Host` все изменяющие запросы получат 403
- «Прогон»: певцы P3+ не обрабатываются
