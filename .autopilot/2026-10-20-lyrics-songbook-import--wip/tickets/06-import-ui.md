## Что должно заработать

Новый пункт меню «Импорт» (`#import`) с вкладками «usdb», «Файлы», «Ссылка». usdb: поля исполнитель/название, язык (по умолчанию «русский», есть «любой»), результаты с «уже есть», «Показать ещё», «Взять» → inspect. Файлы: zip или .txt + аудио + обложка. Ссылка: zip или GitHub. После разбора — карточки песен (галочки, по умолчанию все без дублей), на каждой: исполнитель/название (правятся), что со звуком, поле ссылки YouTube (заполнено найденной), загрузка своего mp3, «Сделать минусовку» (включено), «Заменить» при дубле, предупреждения. «Импортировать выбранные» ставит по заданию на песню и ведёт в очередь. Подсказка, откуда брать русские песни.
