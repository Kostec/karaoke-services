**Волна:** 1

## Что должно заработать

Чистый модуль, который из zip-архива или папки с файлами достаёт список готовых UltraStar-песен: исполнитель, название, язык, дуэт, какое аудио лежит рядом, какая обложка, какие ссылки YouTube и обложки указаны в `#VIDEO`. Безопасно: архив не может записать за пределы папки, не может раздуться больше лимита, лишние файлы игнорируются. Плюс место на томе data для временных распаковок — `imports/<token>/`.

## Из брифа, дословно

> «Импорт готовой песни»
> «Поддержка ссылки на zip тоже хороший вариант»

## Разделы спецификации

Истории 11, 13, 14, 15; Решения §5; Границы: `songpack.py`.

## Критерии приёмки

- [ ] `safe_extract(zip_path, dest, max_total_bytes)`: отказ на `..`/абсолютные пути/симлинки, лимит суммы распакованного, только белый список расширений из спецификации; повреждённый zip → `PackError("Архив повреждён")`; превышение → `PackError("Архив больше N МБ после распаковки")`
- [ ] `find_songs(dir)` — рекурсивно, txt с `#TITLE` и нотами (не `*.lyrics.txt`), кодировки через `ultrastar.decode` (UTF-8, BOM, cp1251); аудио по `#AUDIO`/`#MP3` без учёта регистра имени; обложка по `#COVER` или ` [CO].`; дуэт; язык из `#LANGUAGE`; порядок — стабильный по пути
- [ ] `youtube_links(video_header)` разбирает форму usdb (`a=…,v=…,co=…`, где `a`/`v` — ID или URL) и голые URL/ID; отдаёт `(audio_urls, cover_url)`, `a=` раньше `v=`; ID → `https://www.youtube.com/watch?v=<id>`
- [ ] Нет песен → пустой список (решение об ошибке — у вызывающего); `PackError` с русским текстом
- [ ] `DataPaths.import_dir(token)` и `DataPaths.imports_root`; пути — только через `DataPaths`
- [ ] Тесты: пак из 2 песен в подпапках, cp1251, дуэт, zip-slip, лимит, `#VIDEO` формы usdb; полный pytest зелёный
