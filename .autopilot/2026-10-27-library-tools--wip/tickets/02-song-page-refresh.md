# 02 — Страница песни обновляет только изменившееся и гасит действия при недоступном хранилище

**Требования:** R01, R02, R03, R40i, R07, G01
**Зависит от:** —
**Зона:** `web/static/js/song-page.js` · `web/static/js/song-page-logic.js` · `web/static/js/player.js` · `web/app/api_targets.py` · `tests/frontend/song-page-logic.test.mjs` · `tests/api/test_targets.py`
**Волна:** 1
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

После «Теги…», копирования и готового задания страница песни меняет только блоки с изменившимися данными: играющий плеер не останавливается, раскрытый текст не сворачивается, старые плееры освобождаются. Страница раз в 15 с спрашивает статус хранилища песни (`GET /api/targets/{id}/status`); недоступно — баннер и погашенные пункты «…» и кнопки редакторов, восстановилось — всё возвращается.

## Из брифа, дословно

> «Страница песни перерисовывается целиком после «Теги…», копирования или готового задания. Из-за этого останавливается играющий плеер, а старые плееры не освобождаются. Стоит обновлять только изменившиеся блоки.»
> «Пункты меню «…» не гаснут, если хранилище отвалилось после открытия страницы.»

## Разделы спецификации

Истории 1–5, 9, 10; interfaces.md «фронт: модули и контракт» (`player.js`, `song-page.js`), «web: API» (`/api/targets/{id}/status`).

## Критерии приёмки

- [ ] `blockSigs(details)` в `song-page-logic.js` даёт подписи блоков `hero, media, lyrics, info, store`; смена тегов меняет только `hero`, новая копия — только `store`, новый файл минусовки — только `media` (node-тесты)
- [ ] `song-page.js` пересобирает только блоки со сменившейся подписью; «Медиа» с той же подписью не трогается, и `<audio>` — тот же элемент; раскрытый текст остаётся раскрытым, если `.txt` не менялся
- [ ] `releasePlayers(scope?)` в `player.js` освобождает плееры (pause, снят `src`, `load()`, убраны из реестра); зовётся при замене «Медиа» и в `hide()`
- [ ] `GET /api/targets/{id}/status` → `{ok, error, label}`; неизвестный id → 404; недоступное хранилище → `ok:false` и текст (pytest)
- [ ] Страница опрашивает статус, пока видима; `ok:false` или любой ответ 503 → баннер «Хранилище «X» недоступно — действия с файлами отключены» и `outputOk=false` у пунктов «…» и кнопок редакторов; восстановление снимает баннер
- [ ] Прежние тесты зелёные (205 pass фронта, pytest)
