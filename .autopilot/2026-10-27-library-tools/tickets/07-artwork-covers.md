# 07 — Фон и обложка: задание без GPU, поиск обложек в сети; ссылка на альбом ведёт в Импорт

## Что должно заработать

Задание `artwork` (обложка или фон: свой файл, ссылка на картинку, убрать фон) без GPU. Поиск обложек в iTunes, Deezer и MusicBrainz с выбором из вариантов — в диалоге «Обложка…» (страница песни и «…»), в поле обложки «Новой песни». Диалог «Фон…». Ссылка на альбом/плейлист в «Новой песне» — кнопка «Открыть в Импорте», там она сразу разобрана.

## Из брифа, дословно

> «Своё фоновое изображение (#BACKGROUND): поставить или заменить его так же, как видео, отдельным заданием без GPU.»
> «Обложка из сети: поиск через iTunes, Deezer или MusicBrainz по исполнителю и названию, с выбором из нескольких вариантов.»
> «Пакетная генерация по ссылке на плейлист или альбом: каждый трек становится отдельным заданием, текст ищется автоматически.»

## Разделы спецификации

Истории 12–24, 54–55; «Решения по реализации» (artwork, поиск обложек, A03); interfaces.md «worker: artwork», «web: API» (artwork, covers), «фронт» (`artwork.js`, `new-song.js` + `import.js`).

## Критерии приёмки

- [ ] `POST /api/jobs/artwork` — файл (jpg/png/webp, до `MAX_COVER_MB`), `url` (качает web, публичный адрес, картинка) или `remove`; ровно один; ошибки 400 у поля, 409 дубль (pytest)
- [ ] Воркер без GPU: фон → `<A - T> [BG].<ext>` и `#BACKGROUND`, обложка → `[CO]` и `#COVER`, в `.txt` меняется только эта строка (остальные байты как были, фикстура cp1251/CRLF), прежняя версия в корзину, старый файл другого имени удалён, `remove` снимает строку и файл; restart не принимает файл заново; «Выложить повторно» работает (тест runner)
- [ ] `GET /api/covers/search` собирает варианты трёх сервисов (FakeHttp), сбой одного не валит остальных, все упали → 503, пусто → `items: []`; у MusicBrainz есть `User-Agent`
- [ ] Диалоги «Обложка…» и «Фон…» по макету: сетка вариантов, свой файл, ссылка; поле обложки «Новой песни» заполняет `cover_url` выбранным вариантом
- [ ] Ссылка на альбом в «Новой песне» → «Открыть в Импорте» → вкладка «Ссылка» уже разобрала её (sessionStorage `import.url`); прежние тесты `link-logic`/`folder-logic` зелёные
- [ ] «Медиа» на странице песни: «Обложка» и «Фон» с «Заменить…/Поставить…»; пункты «Обложка…», «Фон…» в «…»
