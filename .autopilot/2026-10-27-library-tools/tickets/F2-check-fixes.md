## Что должно заработать

- [ ] Слепая приёмка: «Кнопка шлёт `POST /api/jobs/video remove=1`, а сервер отвечает 409 «У песни нет видео». Причина: в индексе `video` заполняется, только если файл существует (`storage/base.py:432`), а проверка в `api_jobs.py:588` смотрит именно на него.» — Условие: `remove` разрешён, если в `.txt` есть строка `#VIDEO` (даже когда файла нет); задание снимает `#VIDEO` и `#VIDEOGAP`, прежняя версия `.txt` — в корзину; 409 «У песни нет видео» — только когда нет ни файла, ни строки `#VIDEO`. Тесты: API (постановка для битой ссылки) и runner (строки сняты, файл не трогается).
