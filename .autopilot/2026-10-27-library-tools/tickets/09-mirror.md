# 09 — Зеркало хранилища

**Требования:** R26, R27, R42i
**Зависит от:** 01, 05
**Зона:** `worker/karaoke_worker/mirror.py` · `worker/karaoke_worker/runner.py` · `core/karaoke_core/scan.py` · `web/app/context.py` · `web/app/api_mirrors.py` · `web/static/js/settings.js` · `web/static/js/mirror-logic.js` · `tests/api/test_mirrors.py` · `tests/worker/test_runner_mirror.py` · `tests/frontend/mirror-logic.test.mjs`
**Волна:** 3
**Ревью:** да — удаление данных (замена копий, корзина цели)
**Модель:** сильная

## Что должно заработать

В «Настройках» карточка «Зеркала»: «откуда → куда», вкл./выкл., «Синхронизировать сейчас», итог прошлого прогона и список «только в цели» с «Убрать в корзину». Воркер раз в 30 мин ставит `mirror`, тот пересканирует оба хранилища и ставит `copy`: недостающие — без замены, изменённые — с заменой. Само ничего не удаляет.

## Из брифа, дословно

> «Зеркало хранилища: автоматически поддерживать одно хранилище копией другого, например «Локальное» и Pi. Задание copy для этого уже есть.»
> «4. Ок»

## Разделы спецификации

Истории 44–48; «Решения по реализации» (зеркало); interfaces.md «worker: mirror, планировщик», «core: настройки» (зеркала), «web: API» (зеркала). Ответ «4. Ок» — согласие с тем, что зеркало только добавляет и заменяет изменённые, а песни «только в цели» показываются списком с кнопкой «Убрать в корзину».

## Критерии приёмки

- [ ] Сканирование вынесено в `core/karaoke_core/scan.py` без смены поведения `rescan` (прежние тесты rescan зелёные)
- [ ] `mirror`: нет в цели → `copy` `replace=false, wait=true`; изменилась в источнике (mtime новее прошлого прогона и размеры не совпали) → `replace=true` (+`replace_rel_dir` при другой папке); только в цели — в `last_result.only_in_target`, ничего не удалено (тест runner)
- [ ] Планировщик ставит `mirror` раз в 30 мин на включённое зеркало, не дублирует активное; выключенное и с удалённым хранилищем — не ставит
- [ ] API зеркал: на себя → 400 «Хранилище не может быть зеркалом самого себя», обратное → 400 «Обратное зеркало уже есть», `run` при активном → 409 (pytest)
- [ ] Карточка «Зеркала» по макету; «Убрать в корзину» — после подтверждения, через массовое удаление; цель недоступна — «Ждёт хранилище «X»»
