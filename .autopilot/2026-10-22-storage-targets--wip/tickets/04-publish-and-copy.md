## Что должно заработать

Каждая новая песня (generate, import, republish) выкладывается **сначала в локальное хранилище, потом в основную цель** (если основная — не `local`). В логе — строка «Выложено в «…»» на каждое. Замена старой версии, перенос видео, корзина — в каждом хранилище по прежним правилам `publish_song` (в хранилище, где старой версии нет, — просто выкладка). Индекс обновляется в обоих.

Основная цель недоступна → задание **не падает**: лог «Основная цель «X» недоступна: <причина>; песня сохранена в локальном хранилище и докопируется, когда цель станет доступна», задание `done`, в очередь ставится `copy` с `wait: true`. Недоступно локальное → `failed`, как раньше (`republish` работает).

Задание `copy` (`needs_gpu=False`, берётся и без GPU): params `{rel_dir, txt_name, from_target, to_target, replace, wait}`, ref `{artist, title, song_id}`. `download_dir` из источника в `jobs/<id>/in/` через `DataPaths` (restart не качает заново) → в цели папка уже есть: `replace=false` → «Уже есть в «X» — пропущено», `done`; `replace=true` → прежняя в корзину цели → `upload_dir` → индекс цели. `wait=true` и цель недоступна → задание возвращается в `queued`, `params.retry_at = now+60 c`, этап «Ждёт хранилище «X»», строка лога не чаще раза в 10 минут; `claim_next` пропускает задания с будущим `retry_at` и берёт следующие. Отмена работает и в ожидании. Источник недоступен/песни нет → `failed` с русским текстом. Срока у ожидания нет.

`POST /api/jobs/copy` JSON `{song_ids: [...], target_id, replace: false, only_missing: true}` → `{queued: [job ids], skipped: N, errors: [{song_id, detail}]}`: `only_missing` — пропускает песни, которые уже есть в индексе цели (по `rel_dir`); дубль (та же песня → та же цель уже `queued/running`) → id существующего задания; `target_id` = хранилище самой песни → запись в `errors`; неизвестный `target_id` → 400 `field=target_id`; больше 1000 песен — 400.

`GET /api/songs` и `GET /api/songs/{id}` отдают у песни `pending_copies: [{target_id, name, job_id}]` — активные `copy`-задания с этой песней-источником (только это поле; остальное в `api_songs.py` — таск 05).
