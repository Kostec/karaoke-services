## Что должно заработать

В «Настройках» блок «Куда выкладывать» — список хранилищ: «Локальное хранилище» (первым, без «Изменить/Удалить») и добавленные. У каждого: имя, тип, адрес (метка), состояние после «Проверить», «Изменить», «Удалить», радиокнопка «Основная цель». «Добавить хранилище» → выбор типа → форма → «Проверить» / «Сохранить» (сохраняется только проверенное, как сейчас для SMB). Переключение основной цели не трогает сами хранилища — настройки SMB больше не теряются.

Типы и поля формы:
- **SMB** — сервер (IP), шара, путь, логин, пароль (подсказка: имена `pi.local` в контейнере не работают — только IP);
- **Папка ПК** — обзор каталогов: корень «Папки ПК» (`/host`, `HOST_FOLDERS_ROOT`) или «Локальное хранилище» (`/output`), клики по подпапкам, «Выбрать эту папку»; подсказка, как сменить корень в `.env` и перезапустить;
- **Яндекс Диск** — логин, пароль приложения, путь папки (подсказка: пароль приложения создаётся в id.yandex.ru → Безопасность → Пароли приложений, тип «Файлы WebDAV»);
- **WebDAV** — адрес, логин, пароль, путь;
- **Google Диск** — Client ID, Client secret (подсказка: Google Cloud Console → OAuth-клиент типа «Desktop app», включить Google Drive API), путь папки на Диске, кнопка «Войти через Google» (новая вкладка) → после возврата блок показывает «Подключено», хранилище сохранено; если страница открыта не с `localhost`/`127.0.0.1` — подсказка «Подключите Google Диск с компьютера, где запущен сервис».

API (`web/app/api_targets.py`):
- `GET /api/targets` → `{targets: [public…], default_id, roots: {host: bool, output: true}}`
- `POST /api/targets` — создать (с проверкой `probe`); `PUT /api/targets/{id}` — правка (пустой секрет = прежний, только при том же адресе/логине — иначе 400 `field=password`); `DELETE /api/targets/{id}` (основную — 409 «Сначала выберите другую основную цель»; `local` — 400; индекс `library` этого id стирается, файлы не трогаются); `PUT /api/targets/default {id}`; `POST /api/targets/test` (без сохранения; с `id` — подставляет сохранённый секрет)
- `GET /api/targets/browse?root=host|output&path=` — только каталоги, без выхода за корень, 400 на `..`
- Google: `POST /api/targets/gdrive/draft` (черновик из полей формы, живёт 10 минут в памяти веба) → `{draft}`; `GET /api/targets/gdrive/auth?draft=` → 302 на `accounts.google.com/o/oauth2/v2/auth` (`redirect_uri = <scheme://host запроса>/api/targets/gdrive/callback`, scope `https://www.googleapis.com/auth/drive`, `access_type=offline`, `prompt=consent`, `state=draft`); `GET /api/targets/gdrive/callback?code&state` → обмен кода через `GDriveStorage.exchange_code` (таск 02 идёт параллельно — если его ещё нет на диске, импортируй лениво внутри функции; тесты — через `FakeHttp`-маршрут token endpoint и `storage_factory`-фейк для `probe`), сохранение хранилища, HTML-страница «Google Диск подключён — вкладку можно закрыть» / ошибка по-русски; `GET /api/targets/gdrive/draft/{draft}` → `{state: pending|connected|error, error?, target?}`
- Секреты и токены API никогда не возвращает.

`docker-compose.yml`: web и worker монтируют `${HOST_FOLDERS_ROOT:-D:/}:/host`; `.env.example` — переменная с русским комментарием строкой выше.
