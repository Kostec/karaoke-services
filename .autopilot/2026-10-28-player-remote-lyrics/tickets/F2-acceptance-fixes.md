# F2 — Расхождения слепой приёмки: стрелки застревают в списках, «null» в просмотре текста

**Требования:** R04, R05, G02
**Зависит от:** —

**Ревью:** нет

## Что должно заработать

Слепая приёмка (запуск в браузере) нашла: на «Песнях» стрелками нельзя дойти до списка песен — первое ↓ ставит фокус в выпадающий список «Хранилище», следующее ↓ меняет хранилище (local → SMB); после Esc стрелка снова попадает туда же. На «Настройках» три ↓ уводят фокус на плавающую «+». В «Просмотре» текста под строкой источника видна лишняя строка «null» (`lyrics-dialog.js:79`: у не-Genius варианта в `append` попадает `null`).

## Критерии приёмки

- [ ] Закрытый `<select>` стрелки не меняют: ↑↓←→ уводят фокус, как с кнопки; Enter/пробел открывают список браузера (внутри открытого списка — его стрелки). История 17 читается так: стрелки остаются полю только у `textarea` (и ←/→ у текстового поля/ползунка); тест в `remote-logic.test.mjs`
- [ ] На «Песнях» из шапки раздела ↓ доходит до первой карточки песни и дальше по карточкам; выбранное хранилище стрелками не меняется
- [ ] Плавающая «+» (`#fab-new`) — кандидат только когда в эту сторону нет других элементов; на «Настройках» ↓ идёт по элементам формы до конца страницы
- [ ] Без фокуса первая стрелка ставит фокус на первый элемент основного содержимого экрана (не шапки раздела, если есть список/форма) — на «Песнях» это первая карточка, если песни есть
- [ ] В «Просмотре» текста нет строки «null» ни у одного источника
- [ ] `node --test tests/frontend/` зелёный
