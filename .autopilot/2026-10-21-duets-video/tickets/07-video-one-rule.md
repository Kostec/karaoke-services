## Что должно заработать

Поведение для пользователя не меняется. Правила видео сейчас продублированы в трёх тасках подряд — каждое должно жить в одном месте. Плюс нет теста на критерий истории 30.

## Из брифа, дословно

История 30; Решения «Индекс», «Лимит», «Скачивание видео».

## Критерии приёмки

- [ ] тест воркера: замена песни (generate или import с заменой) с `params.video` → в результате новое видео, старое не перенесено; и парный — «без видео» → старое перенесено (если ещё не покрыт)
- [ ] «видеофайл песни из `#VIDEO`» (имя без пути, расширение из `VIDEO_EXTS`) определяется одной функцией, которую зовут и `Storage` (`SongEntry.video`), и воркер (`_video_name`)
- [ ] текст ошибки расширений и `accept` у поля файла строятся из `naming.VIDEO_EXTS` (фронт получает список из `/api/defaults`; запасной список — только на случай, если сервер не ответил); качества фронт берёт из `/api/defaults`
- [ ] у фронта нет своего списка «запретных для видео» сайтов (`isVideoLink`): признак «ссылка годится для видео» приходит с сервера (inspect / link-inspect отдают его по `musiclink.classify`), либо фронт показывает вариант и полагается на 400 сервера
- [ ] сборка полей видео в FormData — один помощник в `api.js` с именем файловой части параметром; разница имён `video` (`/api/jobs/video`) и `video_file` (generate/import) записана как намеренная в комментарии или убрана (приняв оба имени на сервере)
- [ ] `params.video.height` пишется только у режимов со ссылкой (`url`, `source`)
- [ ] `api_import`: ссылка звука выбирается один раз, «из ссылки песни» берёт её результат
- [ ] фронт и сервер принимают одно множество значений смещения (`videoError` не строже и не мягче `parse_videogap`)
- [ ] разбор вывода yt-dlp в причину сбоя — одна функция для звука и видео, тексты отличаются подписью
- [ ] (приёмка) после завершения задания `video` (прикрепить/заменить/убрать) карточка песни в «Песнях» обновляется сама — метка «видео» появляется/пропадает без перезагрузки страницы (по образцу того, как список обновляется после минусовки, если такой механизм есть; иначе — перечитать карточку по завершении задания)
- [ ] полный pytest и `node --test tests/frontend/` зелёные
